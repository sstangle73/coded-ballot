Check a voting page

Is your organisation's voting page running exactly the published coded-ballot code?

This check runs in your browser, from the project's own site. It downloads the organisation's voting page and compares every file with this release. A fingerprint shown on the voting page itself proves nothing, because a changed page could show the right one.

Or skip the organisation's page: vote from this site's own copy, which only locks your vote with the count key printed on your ballot.
